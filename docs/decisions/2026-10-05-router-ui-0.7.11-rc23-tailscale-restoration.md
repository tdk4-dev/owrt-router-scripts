# RC23: bounded Tailscale restoration

Owner-directed repair for INC-2026-10-05-02. RC22 source
`fc395408b3128bfacd7c912ccdef650f8e1fe062` remains immutable. RC23 is
`0.7.11-rc.23` / `0.7.11~rc23-1` / candidate, based on that unmerged candidate
lineage. Canonical production remains origin/main; this is not a production
release or a claim that RC22 is merged.

The only behavioral change is Tailscale restart/restoration: wait for both
procd and daemon termination; distinguish stop request, stop timeout, state
restoration, start request, start convergence and final invariant failures;
attempt bounded recovery of prior running intent after an accepted stop.
Atomic state-file replacement leaves the current file intact on copy failure.
Boot intent, identity, persistent-state hashes and exact route checks remain
required. Recovery of running intent never changes a failed restoration result
to success. A stop still pending after the final bound remains explicitly
unrecovered; no concurrent start or state overwrite is attempted.

A running/registered restart checks the kernel TUN address and known IPv4 peer
return routes before mutation. These checks detect the incident's damaged
baseline; they do not prove every possible kernel route is healthy. If exact
routing later differs, restoration fails and explains that saved identity alone
cannot reconstruct kernel routing. No policy route is installed by the repair.

Qualification is focused regression tests and a disposable native
OpenWrt/procd/Tailscale lifecycle, with real delayed termination and an isolated
peer management path. Fault injection must be distinguished from actual native
service observations. On passing, prepare/sign one immutable package candidate
with the existing protected workflow. Version allowlists and metadata advance
only to identify RC23; release architecture and package behavior are unchanged.

No destructive owner-router test, full historical matrix, image build, merge,
tag, release, Latest or discovery operation is authorized by this checkpoint.
