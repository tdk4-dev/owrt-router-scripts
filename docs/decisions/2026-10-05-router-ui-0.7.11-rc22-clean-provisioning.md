# RC22: clean package provisioning

Owner decision, 2026-10-05. RC21 source
`e5f4069532e19c4b42fba6e366c581a08ddacb5a` remains immutable, valid legacy-upgrade
evidence. Its clean OpenWrt checkpoint installed the exact three packages but
left setup falsely completed and native Xray unavailable. Authenticated profile
creation was disabled and adoption could not adopt the absent upstream config.

The next unused identity is `0.7.11-rc.22` / `0.7.11~rc22-1` / candidate. This
amends the current acceptance boundary without rewriting earlier decisions:

`supported clean OpenWrt → three project IPKs → healthy unconfigured Premier Router`

The narrow repair separates the online package guard from first-boot completion.
It keeps the public image wizard unavailable on package installations: opening
an unauthenticated account/network reset API is not an acceptable repair.
Package provisioning uses the existing authenticated LuCI VPN Panel. Only the
exact untouched, disabled upstream Xray UCI layout with no live daemon, pending
UCI changes, user configuration, profile, ownership or completion state is
initialized to the native path. Existing/manual/adopted state is unchanged.
The native renderer produces the first validated configuration on profile Use;
the existing VPN Enable control starts the services. Reboot must retain it.

Acceptance is focused source/security tests followed by one provisional set of
three IPKs from the exact clean source and one disposable clean OpenWrt VM.
The VM must prove healthy unconfigured ownership, first-profile Add/Use/Enable
with a valid public-class Reality endpoint, native startup and reboot persistence.
No old Router UI files may seed the baseline. No runtime hotfix is permitted.

Stop after this checkpoint and report exact source/tree and three IPK hashes.
No production signing, reproducibility double build, full 46-control/release VM
matrix, hardware contact, merge, tag, release, Latest or discovery in this task.
Source changes invalidate affected downstream qualification; no RC21 result is
transferred to RC22. RC21 legacy evidence and its separate clean-install failure
remain retained under their original identities.
